## 1. Context

Kestrel Island is a native KDE Dynamic Island (C++20 / Qt Quick / LayerShellQt, notch only, see `AGENTS.md`). The user wants it friendlier and more beautiful in UI and UX, taking what works in Vorssaint's island. A first polish pass already landed (uncommitted in the working tree: `qml/IslandButton.qml`, `IslandAction.qml`, `RollingText.qml`, `ToolsView.qml`, `FocusView.qml`, `MediaView.qml`, `Main.qml`, `tests/test_backend.cpp`, `DESIGN.md`). This plan finishes the job systematically.

**Definition of done:** every page uses one shared token set; Vorssaint's visual-feel strengths listed in §7 are implemented; motion obeys the app setting and KDE's animation factor; all 4 ctest suites pass; all 8 pages have offscreen screenshots that were looked at; one live check on DP-2 passes.

**Non-goals (explicit):** lyrics, play queue, calendar, clipboard, shelf, companion/mascot, Liquid Glass / blur / drop shadow (DESIGN.md forbids), remote artwork, launching the music app from the idle cover, unlocking `notifications/validated`, new data adapters, changing hover/pin semantics, changing the 288x40 compact footprint.

## 7. Design decisions

### Decision 1: Motion contract (gaps 1, 13)
- **Options:** A gate each Behavior individually with `island.animations`; B one `Theme.motion(ms)` helper that returns `animations ? ms * factor : 0`.
- **Decision:** B. Backend gains `animationScale` (double, default 1, read from `kdeglobals` `[KDE] AnimationDurationFactor`, 0 when the app flag is off). All durations in QML are `Theme.dur(n)`.
- **Reversibility:** REVERSIBLE. **Rationale:** one place to audit; honours K1. **Rejected:** A repeats the D1 mistake on every future Behavior.

### Decision 2: Token source (gap 3)
- **Options:** A `pragma Singleton` `Theme.qml` + `qml/qmldir`; B a QObject created in `main.cpp` and exposed as context property `theme`.
- **Decision:** A first (spike M1-T1, U1). If the spike fails its exit command, fall back to B in the same task; B is the committed fallback, not a menu.
- **Reversibility:** REVERSIBLE. **Rationale:** matches how `island` is already provided (context property, `src/main.cpp`); A is the idiomatic QML choice. **Rejected:** converting to `qt_add_qml_module` (bigger blast radius, K3).

### Decision 3: Palette (gaps 3, 4)
- **Decision:** keep black surface `#080809`, ink `#f5f5f7`, secondary `#a7a7af`, one raised tone `#202023` with hover `#2b2b30`, pressed `#3a3a42`, divider `#252529`, accent default `#b8a1ff`, timer `#ffc078`, ok `#9dd7b1`, info `#95bfff`, warn `#e8bf8b`. `Theme.tint` = `island.media.tint` when available and contrast >= 4.5:1 on `#080809`, else accent. Tint drives: compact bars, timeline fill, selected-tab ring, play button fill (darkened to keep white-icon contrast >= 4.5:1). Amber stays for timer.
- **Reversibility:** REVERSIBLE. **Rejected:** per-page palettes (inconsistent), tinting text (legibility).

### Decision 4: Button and artwork feel (gaps 5, 6)
- **Decision:** tabs and utility buttons become rounded-rectangles radius 10 (selected fill `#ffffff1f`, ring only for keyboard focus); transport buttons stay circular; hover scales 1.04 with 120 ms ease via `Theme.dur`; pressed opacity 0.8; disabled 0.4. Artwork radius `size * 0.19`, 0.5 px inner hairline `#ffffff1f`; empty glyph opacity 0.45.
- **Reversibility:** REVERSIBLE. **Rejected:** keeping circles (the Vorssaint sample uses continuous rounded rects for selection; circles read as "mobile").

### Decision 5: Scroll edge fade without shaders (gap 9)
- **Decision:** a reusable `EdgeFade.qml` with two 16 px `Rectangle { gradient }` overlays, black `#080809` to transparent, shown only when `contentY > 1` (top) or `contentY + height < contentHeight - 1` (bottom), opacity animated with `Theme.dur(180)`. Valid because the page sits on the solid black surface (`Main.qml:68`).
- **Reversibility:** REVERSIBLE. **Rejected:** `MultiEffect` mask (extra module, GPU path under software renderer screenshots).

### Decision 6: System page as cards (gap 8)
- **Decision:** top: 2-column card grid (CPU, RAM, GPU 1, GPU 2, Disk, temps folded into each card's subtitle) each with title, symbol, big value, 3 px meter, attention state (value + meter turn warn color at >=85%, disk free <10%). Below: the existing detailed rows stay, collapsed by default behind a "Details" disclosure that remembers its state in memory. Expanded size becomes 520x480 collapsed / 560x568 with details. Data and units unchanged (`island.statistics`).
- **Reversibility:** REVERSIBLE. **Rationale:** AGENTS.md demands real CPU/GPU/RAM/disk; nothing removed. **Rejected:** removing details (user asked for them in 0.3), per-card click-through pages (new navigation depth).

### Decision 7: Dark controls (gap 7)
- **Decision:** new `IslandStepper.qml` (minus, value, plus, bounds, keyboard Up/Down, accessible name) replacing the three SpinBoxes in `FocusView.qml` and the Top offset SpinBox; `IslandCheck.qml` replacing `CheckBox`; display `ComboBox` keeps native popup but gets a custom closed face via `IslandSelect.qml` only if the offscreen screenshot still shows a light face; text fields get a dark custom background. Objects keep their `objectName`s (`focusMinutes`, `displaySelector`, `settingsPage`).
- **Reversibility:** REVERSIBLE. **Rejected:** KDE palette overrides (proven insufficient, K5).

### Decision 8: Escape and navigation (gap 10)
- **Decision:** Escape on pages 4-6 returns to Tools (page 7); on page 7 or others collapses. Add test. Pin button, Settings, Collapse, Switch-activity all stay (V11 not adopted for Pin).
- **Reversibility:** REVERSIBLE.

### Decision 9: Compact title transition (gap 11)
- **Decision:** compact `Text` cross-fades 140 ms (`Theme.dur`) when `island.activity.notice.title`/`selected.title` changes; numeric text in compact uses tabular figures. No layout change.
- **Reversibility:** REVERSIBLE.

### Decision 10: Visual gate (gap 12)
- **Decision:** `scripts/ui-shots.sh` renders all 8 pages offscreen into `/tmp/kestrel-ui/<name>.png` and prints the paths; M-exit criteria require looking at each image. Also fix the `main.cpp:146` message.
